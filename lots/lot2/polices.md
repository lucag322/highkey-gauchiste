# Polices — règles de Luca (26/10/2026)

- **Jamais de guillemets à l'écran** (ni « », ni " ", ni ' ' autour d'une citation).
- Police dramatique seulement pour la citation ciné (validée par Luca). Le reste du texte reste dans la police de base du style.
- Planche de test : lot2/_claude/planche-polices.jpg (accents vérifiés).

| Style | Police base | Police dramatique pour les mots impactants |
|---|---|---|
| Aura N&B | Arial Black (test 1) | **aucune** : Luca a refusé Morganite, mot-clé en rouge en Arial Black |
| Glow | police du test 4 | **aucune** : Luca a refusé Thunder ; **tout le texte en blanc**, halo coloré + contour, jamais de rouge |
| Citation ciné | serif espacée du test 3 | CaslonGraphique-Opti (serif lourde ciné) |


Chemins : ~/Library/Fonts/<nom>.(otf|ttf).
À éviter (accents É cassés ou illisible) : Thunder-*HC, 1492_Quadrata_lim, lapidary roman, Larizo DEMO, MADE Future X HEADER, Array-BoldWide.
Toujours vérifier sur la planche que les accents (É, À, Ç) s'affichent.
