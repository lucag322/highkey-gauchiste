# Outils du montage highkey-gauchiste (Python : ~/.claude/skills/resolve-studio-editor/.venv/bin/python)
- **compkit.py** (exec) : générateur .comp sur le MediaIn exporté du clip. `b = B("X", last=n-1, w=1080, h=1920)` ; `Ref("MediaIn1")` ; `b.merge/xf/text/anim/anim_xy/node` ; `write_clip_comp(b, last, "comps/<n>/F_<rec>.comp", open("comps/<n>/def_<rec>.comp").read())`. Temps du comp = images SOURCE (25/30/50 i/s), 0 = début du clip. Texte : em px = Size × 617,8 (comp 1080 de large). Chaînes UTF-8 ok. `fuid("Screen")` pour les FuID.
- Pièges Fusion : Crop YOffset compté depuis le BAS (YOffset = 1080 − y0 − h) ; un Loader dans un .comp importé est converti en MediaIn mal calé (ne pas utiliser : poser le média en V2 avec `composite`).
- **framing.py** : `plan_views(src, s, n, fps, speed, hint, bounds, vh, zoom, shake, top)` suit le visage (Apple Vision, cache _claude/cache/faces) et garde la tête entière en 9:16 ; `merge_keys(views)` → clés Size/Center d'un Merge sur fond 1080×1920 (voir gen/4/gen4.py `placed`). `bounds` = zone source sans bandeau ni logo.
- **cards.py** (exec après compkit) : `text_cards(...)` cartons mot à mot, halo coloré derrière + contour sombre + lettres nettes.
- **words.py** : `tokens(mots_derush)` (recolle l'/d'/-gauche), `clean()`, `Layout(police, index, em).line(mots, y)` positions par mot (mesures PIL).
- **fx.py** : effets numpy/cv2 (crop_view, gblur, motion_blur, zoom_blur, vignette, grain, rgb_split, slices) + `write_seq` / `encode(dossier, sortie.mov)` ProRes.
- **decoupe.py** (collages, à utiliser pour toute découpe de personne) : `from decoupe import masques, controle, bas_dechire, planche`. `masques(frames, box, pt, dossier)` = instance Vision de la personne au point `pt` croisée avec la segmentation personne (sans pupitre, micro, voisin), une seule forme, fentes du micro refermées, lissée dans le temps (binaire `perso`). `controle(m)` : bords du box touchés (membre coupé) et `bas_net` (buste coupé à plat) ; `bas_dechire(m)` : bord bas en papier déchiré si le buste ne touche pas le bas du cadre. `planche(...)` : découpes sur magenta, à regarder.
- **segment** (binaire Swift) : `segment <dossier_png> <dossier_masques>` détourage personne (Vision). **faces** : `faces <dossier>` → faces.json. **eyes** : pupilles.
- **luts.py** : LUT .cube des styles dans _claude/luts (FileLUT dans les comps).
- **sheet.sh** : `sheet.sh in.mp4 out.jpg [fps=1] [colonnes=6] [largeur=180]` planche contact horodatée. **checkcut.py** `export.mp4` : liste les têtes coupées (à 0 avant d'annoncer). **segref.py** : découpe une réf en plans (noir/blanc/image).
- **rhelp.py + build.py** (exec dans run_script_unsafe) : `build_timeline(plan)` depuis plan<n>.json (video: clip, folder, s, e en images source, rec en images timeline, track, composite), `export_defaults(tl, n, [préfixes])`, `run_local(cmd)`, `apply_comps(tl, n)` (page Media), `render(tl, chemin, wait=40)` 540×960. Fichier régénéré sous le même nom → `MediaPoolItem.ReplaceClip(chemin)` sinon erreur de décodage.
- Audio : voix extraites aux timecodes dans _claude/audio, `duck.py` pour l'enveloppe de musique ; viser ≈ -14 LUFS, crête < -1 dBFS.
- **Ralentis = Resolve uniquement (Optical Flow)** : dans plan<n>.json, mettre `"speed_pct": 50` sur l'item et lui donner le nombre d'images source d'un plan à vitesse NORMALE de même durée (`e - s = durée_timeline/30 × fps_source`). `build_timeline` fait `SetSpeed({"Percentage": 50})` (durée gardée, source raccourcie) + `RetimeProcess = RETIME_OPTICAL_FLOW` + `MotionEstimation = MOTION_EST_SPEED_WARP_BETTER`. Fusion travaille AVANT le ralenti, en images source : longueur du comp = RenderRange du def_<rec>.comp (+1), et `plan_views(..., speed=1.0)`. Jamais TimeSpeed/TimeStretcher (décalage temporel dans Resolve) ni ralenti Python/ffmpeg.
- Plein écran 9:16 obligatoire (pas de letterbox) ; `checkcut.py` doit sortir 0 tête coupée ; planche à 2 i/s vérifiée avant export.
- **Piège audio HD** : après régénération d'un mix sous le même nom, Resolve peut garder l'ancien son même après ReplaceClip. Après chaque rendu HD, remuxer le mix du plan avec ffmpeg (-map 0:v -map 1:a -c:v copy -c:a aac -b:a 320k) et comparer LUFS / true peak au WAV.
- **zones_tiktok.py** `<video> [fps=2]` : lit les textes de l'image (Apple Vision, binaire `texts` compilé depuis texts.swift) et les visages (binaire `faces`, visages ≥ 4 % de la hauteur), et liste ceux qui passent sous l'interface TikTok. Zone sûre des textes et visages : x 0,17-0,83 (bloc centré ≤ 66 % de large, colonne de boutons à droite de 0,34 à 0,86 de haut), y 0,12-0,75 (onglets en haut, pseudo et légende en bas). Appelé par verif_apercu.sh.
